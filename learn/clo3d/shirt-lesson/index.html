男士衬衫吧

从男士基础版开始，把胸省与肩省的松量转移到领口和袖窿。跟着录屏理解切开、合省与旋转的关系，再设计自己的衬衫版型。

01

准备版片与模特

从男士基础版开始

打开课程文件，里面已经有男士基础版片。先加入虚拟模特，再把版片放到模特身上对应的位置，为接下来的版型调整建立 2D 与 3D 的对应关系。

  1. 在「文件」菜单打开已有的男士基础版。
  2. 加入虚拟模特；选中板片，在 3D 窗口将它放到相应身体区域。录屏中演示了前片的安排。
02 → 05

接下来，开始改板片

这一步就是版型设计。录屏里的数值只是示范，不必完全照抄；理解松量从哪里收起、又在哪里打开，就能按同样的逻辑设计自己想要的衬衫。

02

胸省 → 领口

切出可旋转的小板片

希望领口多一点松量，就先从胸省省尖向领口切开，让这一块前片可以单独旋转。

  1. 按 G 使用「半片内部线」，从胸省省尖画到领口；双击结束线段。
  2. 选中这条内部线，右键选择「切断」。切开后得到一块可单独操作的小板片。
03

关闭一处 · 打开另一处

合胸省，打开领口

让原来胸省的两侧在省尖处对齐，再以省尖为中心旋转小板片。胸省收小的量，会转移到领口形成新的开口。

  1. 将原来的两个省道点尽量重合；拖动时按 Ctrl（Mac 按 Command）可细调位置。
  2. 双击旋转中心，将它移到省尖，再旋转板片。观察领口打开的宽度，按想要的松量决定旋转角度，无须照抄录屏数值。
04

肩省 → 领口与袖窿

为肩省转移做两处切口

前片的袖窿也需要松量。和前一步同理，以肩省省尖为起点，分别向领口与袖窿画内部线，再把两条线切开。

  1. 按 G，从肩省省尖向领口画线；再从同一省尖向袖窿画线。每条线双击结束。
  2. 分别选中两条内部线，右键「切断」，得到可围绕省尖旋转的小板片。
05

把松量放到想要的位置

先开领口，再转到袖窿

把切出的板片重新以肩省省尖对齐。先给领口留一点开口，再旋转左侧小板片，关闭肩省，让更多松量转移到袖窿。

  1. 对齐省尖，先旋转靠领口的小板片，留出少量领口松量。
  2. 再旋转左侧小板片，使肩省闭合，同时观察袖窿处打开的量。按希望的造型调整，不必追求录屏里的角度。
版型小贴士

一般会在前片领口留出一些松量；后片领口可视设计需要决定是否增加。避免只给后片领口加松量、前片却完全不加。

这一节完成了基础版前片的主要松量转移。可以回看两组开合：胸省 → 领口，肩省 → 领口与袖窿。
