Module 02 / Image model logic

图像模型如何
生成与修改画面

模型从训练样本中学到文字、构图、光线和材质之间的关系。生成时，提示词、参考图和选区决定模型要满足的条件。换随机种子通常能看到同一条件下的不同结果。

扩散 / 流匹配
文字与参考图 → 条件

编码提示词和视觉参考，将主体、风格或构图作为生成条件。

↓
噪声 → 逐步变成图像表示

扩散模型学习怎样逐步去噪。流匹配学习在每一刻把随机表示往哪个方向推，采样时沿着这些方向推进。DiT 指用 Transformer 做这一步的网络结构。

↓
图像表示 → 输出

如果生成发生在潜空间，最后由解码器还原为像素。

自回归 / 混合架构
文本与图像 → 上下文

把要求和参考图转成模型可处理的表示。

↓
上下文 → 依次生成图像表示

模型根据已有内容预测下一部分。部分研究在每一步再用扩散生成连续的视觉表示，把两种方法结合起来。

↓
图像表示 → 输出或接着改

支持多轮编辑的产品可把前一轮图像作为新输入。具体实现以模型公开资料为准。

Reference images / One variable

同一个主体，只改灯光

保留参考图的人物身份、发型、姿势、构图与背景。只把主光改成柔和正面光，让阴影边缘更柔和，保留发丝细节。

核对结果时，先对比原图和输出，检查承诺保留的部分有没有一起变化。有选区功能时，可圈出允许修改的区域。

发型结构

先判断轮廓、长度与发丝运动。告诉模型哪些发型细节必须保持不变。

结构刘海轮廓发色发丝运动

脸型气质表情妆容皮肤质感

Module 02 / Visual library · 05

SCENE
场景世界

场景不是漂亮背景，而是人物与发型所属的时间、地点和空间逻辑。

影棚建筑自然城市未来
保持同一个人物、面部长相、发型、头部角度和身体姿势。只将背景替换为安静的现代主义混凝土室内空间，使新背景的透视、光线方向和人物原图准确匹配。空间极简、干净、有建筑感，不增加多余装饰，不重新设计发型。
Module 02 / Visual library · 06

MATERIAL
材质语言

用材质建立触感和世界观。每张参考图只负责一种明确的表面质感。

金属玻璃水混凝土烟雾
保持模特的面部长相、发型、姿势、光线和画面构图不变。只将人物皮肤材质转换为光滑的抛光银色金属，保留原有五官结构、毛孔起伏和真实面部细节。金属反射与原图光源方向一致，高光受控，不影响头发材质，不改变人物身份。

Module 07 / AI basics · Agent

把缰绳握在
自己手里

用 Agent 操作工具之前，先想清楚你要的画面。像写小说一样，先知道人物是谁、置身何处、这一幕要让观众感受到什么，再决定镜头、光线和风格。

先定方向。说明画面的情绪、风格和必须保留的细节。

再交给 Agent 执行。让它调用你选定的工具，按同一组要求试出几个版本。

最后做取舍。用自己的判断选片，告诉 Agent 下一轮该改什么。

你是骑手。缰绳握在你手里，往哪里走、什么时候转向、在哪里停下，都由你决定。Agent 可以按你的方向试出不同走法，让你有更多版本可以比较。

每个人都可以成为创意的决策者。你决定作品要表达什么，AI 负责把想法做出来。
